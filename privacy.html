プライバシーポリシー

最終更新日: 2026年5月19日

VendiMap（以下「本サービス」）における、利用者の個人情報・利用情報の取り扱いについて以下のとおり定めます。本サービスは個人開発者により提供されており、運営者と利用者の間で本ポリシーが適用されます。

1. 収集する情報と利用目的

本サービスは、以下の情報を利用者の端末上で扱います。

情報取得方法利用目的保存場所
位置情報（緯度・経度） ブラウザのGeolocation API（利用者の許可後のみ） 近くの自販機の表示、地図中心の設定 端末内のみ（送信されません）
地図の表示位置・ズーム 地図の操作から取得 次回起動時の状態復元 端末の localStorage
お気に入り登録 利用者による登録操作 お気に入り一覧の表示 端末の localStorage
検索結果のキャッシュ 検索時に自動取得 外部APIへの負荷軽減・表示の高速化 端末の localStorage（1時間で自動破棄）
自販機の存在/撤去報告 利用者がポップアップから「ある／ない」をタップ 地図表示の補正、ユーザー自身による品質改善 端末の localStorage（手動エクスポートまで保持）

これらは利用者の端末内でのみ管理され、本サービスのサーバーには送信・保存されません（本サービスは独自のサーバーを持ちません）。

2. 第三者サービスとの通信

本サービスは、表示と検索のため以下の第三者サービスと通信を行います。各サービスのプライバシーポリシーが適用される場合があります。

  • Overpass API（OpenStreetMap） — 自販機の位置データを取得するため。検索範囲（緯度・経度・半径）が送信されます。
    参照: Overpass API
  • MapTiler — 地図タイルの取得のため。表示中の地図領域の座標が送信されます。
    参照: MapTiler プライバシーポリシー
  • GitHub Pages — 本サービスのホスティングのため。アクセスログが取得される場合があります。
    参照: GitHub Privacy Statement

これらの通信にはネットワーク経路上で利用者のIPアドレス等が含まれる場合があります。各サービスでの個別の取り扱いは、各社のポリシーをご確認ください。

3. Cookieについて

本サービスは Cookie を使用しません。利用者の情報は端末の localStorage のみで管理されます。ブラウザの設定から localStorage を削除すれば、保存された情報はすべて消えます。

4. 解析・トラッキング

本サービスは、利用状況を改善する目的で GoatCounter によるアクセス統計を任意で取得する場合があります（運営者が有効化した場合のみ）。GoatCounter は以下の特性を持ち、Cookie を使用しません。

  • 収集する情報: 訪問URL、リファラー、画面サイズ、ブラウザ言語、おおまかな国情報、本サービス上で発生したイベント（検索成功・現在地取得・お気に入り登録など）
  • 送信されないもの: IPアドレスは保存されず、個人特定情報は収集されません
  • 位置情報・お気に入りの内容は GoatCounter には送信されません
  • 運営者の方針として、追跡広告目的のトラッキングは行いません

詳細は GoatCounter プライバシーポリシー をご参照ください。

5. データの第三者提供

本サービスは、利用者の同意なく利用者の情報を第三者に提供しません。本サービスはサーバー側にデータを保存しないため、提供できるデータも保持していません。

6. 利用者の権利

利用者は以下の操作を任意のタイミングで行えます。

  • 位置情報の利用を拒否する（ブラウザの権限設定から）
  • localStorage に保存された情報を削除する（ブラウザの設定 → サイトデータの削除）
  • 本サービスの利用を中止する

7. 子どもへの対応

本サービスは年齢制限なしで利用可能ですが、位置情報の利用には保護者の同意・配慮を推奨します。

8. ポリシーの変更

本ポリシーは法令の変更・サービスの拡張に応じて改定される場合があります。変更時は本ページの最終更新日を更新します。重大な変更がある場合はアプリ内・GitHubでも告知します。

9. お問い合わせ

本サービスに関するお問い合わせは、GitHubリポジトリのIssueからお願いします。
